# 01 — Intro & Philosophie Client-First

> **Source :** [finsweet.com/client-first/fr/intro](https://finsweet.com/client-first/fr/intro)

---

## Le problème de base

Si vous avez déjà développé un site sur Webflow, vous connaissez forcément la problématique suivante :

```
Div Block 765
Image 37
Text Block 22
heading_w-42
```

Ces classes ont un nom. Sauf que... **personne ne connaît le rendu**, pas même celui qui les a créées 😅

---

## Qu'est-ce que Client-First ?

**Client-First** est une méthode qui permet de rester organisé dans vos projets Webflow, grâce à un **langage universel de nomination des classes**.

👉 Il s'agit d'un système de styles complet : classes, dossiers, structure de page, typographie et espacement.

---

## La mission Client-First

| Objectif | Détail |
|---|---|
| 🏗️ Système organisé | Pour tous vos projets |
| ⚡ Productivité | Plus de rapidité et flexibilité dans le Designer |
| 📛 Nommage CSS | Stratégie claire de nomination des classes |
| 📐 Structure standard | Pages identiques sur l'ensemble du site |
| 🔧 Maintenabilité | Site facilement administrable, prêt à évoluer |
| 👥 Compréhension | Développeurs, clients, toute personne comprend le projet |

---

## Que signifie "Client-First" ?

**Client-First = "Le client d'abord"** — un état d'esprit qui priorise les clients dans le processus de création Webflow.

La plupart des clients souhaitent :
- Un projet avec une **base solide**, prête à évoluer
- Un projet **rapide**, sans perdre en qualité
- Des développeurs **rigoureux**
- Un produit **compréhensible par tous**, quelle que soit l'agence
- Un projet gérable depuis le mode **Designer**

---

## Convention de nomination

L'approche Client-First met l'accent sur une **dénomination explicite des classes** :

- Un développeur, un client ou toute autre personne doit pouvoir **comprendre le rôle d'un élément** juste en lisant le nom de sa classe
- Les classes sont **prédictibles** et suivent des **patterns reconnaissables**
- Le système utilise des **préfixes** pour catégoriser les classes

---

## Prérequis

Avant d'apprendre Client-First, maîtrisez :
- ✅ Les bases de **Webflow** (Designer, panneaux)
- ✅ Notions de **HTML** (structure, balises)
- ✅ Notions de **CSS** (classes, propriétés, cascade)
- ✅ Différence entre **classes globales** et **classes personnalisées**
