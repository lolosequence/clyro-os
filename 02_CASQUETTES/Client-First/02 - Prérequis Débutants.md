## L'essentiel avant Client-First

Une grande partie de Client-First ne sera pas claire pour quelqu'un qui n'a aucune expérience du web. Il faut avoir une connaissance **niveau débutant**.

---

## Définitions clés

### Outils no-code
Outils qui permettent de créer sans code, là où le code serait normalement nécessaire. Les outils no-code suppriment tout ou partiellement le code du processus de création.

### Webflow
Outil no-code pour la création visuelle de sites web. Webflow élimine la plupart du HTML, CSS et Javascript qui doivent normalement être écrits manuellement.

### Finsweet
Leader de l'écosystème Webflow dans le travail en agence, la création de contenu, les outils et les ressources.

## Les 3 piliers du web

| Langage | Rôle | Analogie maison |
|---|---|---|
| **HTML** | Structure et contenu | Les matériaux (murs, toit) |
| **CSS** | Styles et mise en page | Le plan, les couleurs, le design |
| **JavaScript** | Fonctionnalité et interactivité | L'électricité, la plomberie |

## Classes CSS

### Classe globale (Global Class)
- Créée une fois, réutilisable partout
- Toute modification affecte **tous les éléments** utilisant cette classe
- ⚠️ Puissant mais dangereux si mal utilisé

### Classe personnalisée (Custom Class / Combo Class)
- Créée pour un élément spécifique
- Peut combiner plusieurs classes
- Modifications locales uniquement

---

## Notions CSS à maîtriser

- `display` : block, inline, flex, grid, none
- `position` : static, relative, absolute, fixed, sticky
- `width` / `height` : px, %, vw, vh, rem, em
- `margin` / `padding` : espacement extérieur / intérieur
- `flexbox` : alignement et distribution dans un conteneur
- `grid` : mise en page en grille (CSS Grid)
- `font-size` / `font-weight` / `line-height` / `color`
- `background` : couleur, image, dégradé
