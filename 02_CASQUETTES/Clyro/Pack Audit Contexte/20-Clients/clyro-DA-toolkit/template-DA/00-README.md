# 🎨 Template Dossier Client DA — Clyro

> Structure standardisée pour chaque projet de Direction Artistique.
> Copier ce dossier entier pour chaque nouveau client.

---

## Arborescence

```
📁 [NOM-CLIENT]-DA/
├── 📄 00-README.md                    ← Ce fichier
├── 📄 01-BRIEF.md                     ← Brief structuré (output da-brief-extractor)
├── 📄 02-BENCHMARK.md                 ← Analyse concurrents
├── 📄 03-MOODBOARDS.md                ← 3 directions visuelles (output da-moodboard-curator)
├── 📄 04-DIRECTION-RETENUE.md         ← Direction validée par le client
├── 📄 05-COLOR-SYSTEM.md              ← Système de couleurs complet (output da-color-system)
├── 📄 06-TYPOGRAPHY.md                ← Système typographique (output da-typography-selector)
├── 📄 07-DESIGN-SYSTEM.md             ← Design system complet
├── 📄 08-BRAND-KIT.md                 ← Livrable client final (output da-livrable-generator)
├── 📄 09-VOICE-EDITORIAL.md           ← Guide vocal et éditorial
├── 📄 10-CHANGELOG.md                 ← Historique des versions et décisions
│
├── 📁 assets/
│   ├── 📁 logos/                      ← Fichiers logo (SVG, PNG, variations)
│   ├── 📁 moodboard-images/           ← Images de référence collectées
│   ├── 📁 palette/                    ← Swatches couleurs exportés
│   └── 📁 fonts/                      ← Fichiers fonts téléchargés
│
├── 📁 exports/
│   ├── 📁 pdf/                        ← Livrables PDF client
│   ├── 📁 figma/                      ← Liens Figma ou exports
│   └── 📁 versions/                   ← Versions archivées des livrables
│
└── 📁 references/
    ├── 📁 pinterest/                  ← Screenshots ou URLs Pinterest
    ├── 📁 dribbble/                   ← Screenshots ou URLs Dribbble
    └── 📁 concurrents/                ← Screenshots sites concurrents
```

---

## Ordre d'exécution des skills

```
Phase 1 — Brief & Analyse
  → Skill: da-brief-extractor       → produit: 01-BRIEF.md
  → Manuel: benchmark concurrents   → produit: 02-BENCHMARK.md

Phase 2 — Inspiration
  → Skill: da-moodboard-curator     → produit: 03-MOODBOARDS.md
  → Validation client               → produit: 04-DIRECTION-RETENUE.md

Phase 3 — Identité
  → Skill: da-color-system          → produit: 05-COLOR-SYSTEM.md
  → Skill: da-typography-selector   → produit: 06-TYPOGRAPHY.md

Phase 4 — Système
  → Manuel: Figma design system     → produit: 07-DESIGN-SYSTEM.md

Phase 5 — Livrable
  → Skill: da-livrable-generator    → produit: 08-BRAND-KIT.md
  → Manuel: guide vocal             → produit: 09-VOICE-EDITORIAL.md
```
